# GitHub Pages

Live URL: https://ritwikagarwal.github.io/transit-affordability/

Publish from the `main` branch, `/ (root)`, in Settings > Pages.
The editable HTML, JavaScript, CSS, images and JSON snapshots are the final static output. No package installation, compilation or server process is needed.

Run `npm test` before publishing. Use `python3 run.py` for local viewing. Keep URLs relative so the site also works under project and custom-domain subpaths. The Station Lab handoff points to the sibling `transit_try` project.

The original local folders and the `aboutme` repository are unchanged.
